## Context

HangedMan is an Android learning project. `MainActivity` implements the game interaction, while `Palabras` maps a selected category to the generated word choices.

## Structure

The source includes ten word categories, Android layout resources, and drawable images for successive hangman states. Gradle declares an Android application using Java 8 language compatibility, AppCompat, Material components, and ConstraintLayout.

## Current evidence

The repository contains the app sources and build configuration. This catalog does not claim a current store release, compatibility with current Android versions, or a fresh successful device run.
