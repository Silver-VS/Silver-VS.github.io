## What is in the repository

Learning contains a small C++ source file with an absolute-value function, a two-argument sum, and output through both C-style printing and C++ streams. The repository description identifies it as the start of a C++ learning journey.

## Why keep a small exercise

An early exercise does not need to become a featured Work project. A Notebook record preserves its learning context and gives it a place in the chronological archive without suggesting a larger application exists.

## Boundary worth investigating

The absolute-value implementation negates a negative integer. The most negative representable signed integer cannot always be negated into the same type. That edge case is a useful follow-up question, not a result measured in this repository audit.
